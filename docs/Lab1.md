# Lab 1 - A365 overview
Time: 5 minutes
Objective: Review the Microsoft Admin Centre
Detailed walkthrough
Validate access
1.	Sign in with the workshop account supplied by the instructor.
2.	Open Microsoft 365 Copilot (https://copilot.cloud.microsoft) and confirm that the option to create a new agent is available.
3.	Open Copilot Studio (https://copilotstudio.microsoft.com), select the workshop environment, and confirm that you can create an agent.
4.	Open the Microsoft 365 admin centre (https://admin.microsoft.com) and navigate to Agents. Confirm that the overview and registry pages load.
Exercise 1.2 - Prepare some test data
1.	In SharePoint (SharePoint | Build), create a new site of your choice to build an agent with, using Copilot in SharePoint with a prompt.
2.	Add some test documents for the agent to use.
3.	Include one synthetic sensitivity scenario, for example a fake employee identifier and a fake project codename. Never use real personal, confidential, or regulated information.
4.	Confirm that all attendees have read access using the security group “Sheep Herders”.
