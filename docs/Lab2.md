# Lab 2 - Explore Agent 365 and the unified registry
Time: 5 minutes
Objective: View and filter the agent registry.
Detailed walkthrough
Part A - View the agents
1.	Sign in to the Microsoft 365 admin centre with the workshop agent-administrator account.
2.	In the left navigation, select Agents, then All agents, then Registry. If the navigation is collapsed, select Show all first.
3.	Wait for the summary cards and results grid to finish loading.
4.	Look at the visible counts for total agents, ownerless agents, unmanaged agents, and any risk or activity summaries available in the tenant.

Part B - Inspect and filter the estate
1.	Look at the Agent filters
2.	Click on some agents and add a tag
3.	Filter by the tags – this is a great way to focus on the agents that matter to you
4.	Search for an instructor-designated test agent. Select the result to open its details pane or agent page.
5.	Review Overview, Owners, Users, Capabilities, Connections, Activity, and Security or compliance information where those tabs are available.
6.	Move to the Map view.
7.	Click around and explore.
