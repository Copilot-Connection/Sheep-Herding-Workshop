Notes from the hill

Three games, three ideas from your Hill Farm 365 map. These are simplified metaphors, not simulations of Microsoft security products.

01 / Observe — Know your flock

Chase the eight wandering sheep and get close enough to tag them automatically, or press E to reach a little farther. They scamper away when approached, but you are faster. Tap a sheep to follow it as it moves; tap the ground to walk there. Caught sheep settle down, so you can tell who is already recorded. The flock book represents an agent registry; ear tags represent identity; the bell represents telemetry. Recording a problem is not the same as fixing it.

Agent registry on Microsoft Learn

02 / Govern — The right field, not every field

Grey stone obstacles block both the farmhand and sheep. Plan a route around them, keeping space behind each sheep so you can push it.

Connect four sheep-agents to their approved tools in the larger sorting yard. A connects to Search (read-only), B to Documents (draft-only), C to Mail (internal-only), and D to Records (approved fields). There is one guardrail block per sheep, spread around the yard. Push each agent onto its matching lettered block to apply its guardrail, then into its matching tool socket. Other agents are denied at that block, and tools reject agents whose guardrail has not been applied. Your farmhand can walk through any guardrail. You cannot pull sheep, so leave room to stand behind them. Undo is unlimited, and there is no time limit. These letter-matching rules illustrate scoped access, not real product configuration.

Agent ID governance on Microsoft Learn

03 / Secure — The right response

Select a control, then tap a threat or its lane. Defender counters prompt-injection wolves; Purview counters data leaks; Entra counters impostor identities; Intune counters untrusted devices. Block 20 threats before five get through. Different controls complement one another; none is a universal shield.

Your farmhand

Rowan the shepherd, Pip the sheepdog, Clover the sheep, or Wren the owl. All four have the same abilities: choose a favourite without changing the difficulty. Use Escape or Pause to take a break. Opening this guide also pauses the game.

Progress is kept locally when browser storage is available. The game also works directly from a file and makes no network requests.
