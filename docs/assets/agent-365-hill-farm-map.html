New agents come down the lane every day. Agent 365 lets you observe, govern and secure the whole flock, wherever it was bred. Microsoft Learn describes Agent 365 as the control plane for IT and security leaders to observe, govern and secure agents across the organisation. Generally available for the Commercial segment since 1 May 2026. Licensed per user, available standalone and included in Microsoft 365 E7. Agent 365 overview ↗ · Documentation ↗

Observe

Lookout Fell

Real-time visibility of the flock: one registry, a map, the numbers, the logs and the strays. Ear tags (Microsoft Entra Agent ID) make every sheep identifiable, which is what the rest of the farm depends on.

O-1

AGENT REGISTRY

The Flock Book

Every pedigree flock keeps a flock book. The Agent registry is one central list of every agent available in your organisation.

HowAgents › All agents › Registry. It counts total, ownerless and unmanaged agents, and syncs in agents from other registries.

ValueOne book for every sheep, wherever it was bred.

NoteRisk signals need an E7 or Agent 365 licence. The registry Graph API is in preview.

Where you see it Microsoft 365 admin center

Read moreAgent registry

O-2

MICROSOFT ENTRA AGENT ID

Ear-Tag Pen

The ear tag says exactly which sheep is which. Agents that Agent 365 discovers can be given their own first-class identity in Microsoft Entra Agent ID.

HowEntra shows every agent: those with an Agent ID, self-registered agents and shadow agents.

ValueIf you can’t tell the sheep apart, you can’t govern them.

Where you see it Microsoft Entra

Read moreEntra capabilities for Agent 365Security for Agent 365

O-3

AGENT MAP

Watchtower

From the tower you see every flock on the hill. The Agent map groups agents by the platform they were built on, including Amazon Bedrock and Google Vertex clusters.

HowAgents › All agents › Map. You need the Global Administrator or AI Administrator role.

ValueSee the whole hillside at once.

NoteNeeds an E7 (Agent 365) licence. The single-agent map (one agent, its users and the tools it calls) is in preview.

Where you see it Microsoft 365 admin center

Read moreAgent map

O-4

AGENT OVERVIEW AND ANALYTICS

Counting Stile

Count them over the stile. The Agent overview gives a 30-day snapshot of agent activity and suggests actions.

HowHeadline numbers: agents in the registry, active users, agent run-time and registry sync. Also shows pending requests, agents at risk, agents without owners and agents with exceptions.

ValueKnow how many sheep you have, and which ones need you.

NoteAgent 365 licences are only needed to collect data for third-party agents.

Where you see it Microsoft 365 admin center

Read moreAgent overview

O-5

ACTIVITY AND AUDIT LOGS

Shepherd’s Hut

The shepherd’s hut keeps the flock log. Agent prompts and responses are captured in the Microsoft Purview unified audit log.

HowLogs agent-to-human, human-to-agent, agent-to-tool and agent-to-agent activity. Agent instances are switched on for audit automatically.

ValueWho did what, when, and to which sheep.

Where you see it Microsoft Purview

Read morePurview for Agent 365

O-6

OBSERVABILITY TELEMETRY FOR AGENTS YOU BUILD

The Bellwether

The bellwether wears the bell so you can hear where the flock is heading. Agents your developers build send telemetry the same way.

HowThe Agent 365 SDK connects an existing agent for identity, governed tools and notifications. For new observability work, Microsoft says to install Microsoft OpenTelemetry separately.

ValueHear what your home-bred agents are doing.

NoteThe original Agent 365 Observability SDK is deprecated.

Where you see it Your code (Python, JavaScript, .NET)

Read moreAgent 365 SDK

O-7

SHADOW AI

Bracken Strays

Black sheep hiding in the bracken. Shadow AI helps admins discover, monitor and govern unmanaged AI agents running on devices.

HowAgents › Shadow AI. Needs Defender for Endpoint, Microsoft 365 E5 and Intune enrolment. Finds tools such as OpenClaw, OpenCode and the ChatGPT, Claude, Ollama and Poe desktop apps.

ValueFind the strays before the wolves do.

NotePreview (Frontier). Only OpenClaw can be blocked today.

Where you see it Microsoft 365 admin center

Read moreShadow AI

Govern

The in-bye paddocks

Fences, gates and walls: consistent guardrails for the agent lifecycle, access and compliance, set from the Microsoft 365 admin center, Microsoft Entra and Microsoft Purview. The tools live in the tool shed.

G-1

LIFECYCLE ACTIONS AND ADMIN ROLES

Five-Bar Gate

The gate decides who comes in and who goes out. From the registry, admins install, activate, block, unblock and delete agents, assign owners, publish to the store or reject submissions.

HowActivating an agent needs AI admin approval and can apply a policy template. Delete is a soft delete you can undo for 30 days. Only Global and AI Administrators can install, change or approve agents.

ValueAgents join on purpose, not by accident.

Where you see it Microsoft 365 admin center

Read moreAgent actionsRoles and permissions

G-2

RULE-BASED LIFECYCLE AUTOMATION

Sorting Race

The race sorts sheep automatically as they run through. Rules enforce lifecycle policies, such as flagging ownerless agents or blocking risky ones.

HowRule-based lifecycle automation is one of the features included with Microsoft 365 Enterprise, Business, Education and Frontline plans.

ValueThe flock sorts itself to your rules.

Where you see it Microsoft 365 admin center

Read moreAgent overviewService description

G-3

POLICY TEMPLATES

Dry-Stone Walls

Walls built to one pattern give every field the same shape. The default template bundles Entra, Purview, SharePoint and Defender policies.

HowCustom templates can add Entra Conditional Access policies, access packages and custom security attributes. Templates apply when an agent is activated, not to agents that are already approved.

ValueThe same guardrails for every new field.

NoteNeeds E7 or Agent 365. Scenarios for AI templates are in preview for Frontier tenants.

Where you see it Microsoft 365 admin center

Read morePolicy templates

G-4

OWNERS, SPONSORS AND ACCESS PACKAGES

Sponsors’ Noticeboard

Every field has a named farmer on the board. Entra Agent ID governance uses access packages to grant agents groups, API permissions and Entra roles.

HowAccess can be requested by the agent or its sponsor, or assigned by an admin. If a sponsor leaves, sponsorship moves to their manager, and Lifecycle Workflows tell sponsors what needs doing.

ValueNo orphan sheep.

NoteNeeds E7, or Agent 365 plus Entra P1 or Microsoft 365 E3.

Where you see it Microsoft Entra

Read moreAgent ID governance

G-5

CONDITIONAL ACCESS FOR AGENTS

Cattle Grid

A cattle grid lets the right traffic through and stops wandering sheep. Conditional Access policies can target the user (on-behalf-of), the agent identity or blueprint (app-only), or the agent’s own user account.

HowRisk-based access decisions from Microsoft Entra, applied to agents as well as people.

ValueOnly the right traffic crosses.

NoteIt only protects resources secured by Microsoft Entra ID, so API-key access isn’t covered. Needs E7, or Agent 365 plus Entra P1 or E3.

Where you see it Microsoft Entra

Read moreConditional Access for agents

G-6

TOOLS GATEWAY AND MCP SERVERS

Tool Shed

Every tool an agent can reach for lives in one shed. Connect an AI gateway (Azure API Management AI Gateway or LiteLLM), then allow or block each MCP server from Agents › Tools.

HowNeeds a one-time Global Admin consent. Per-tool control works with the API Management AI Gateway. Bring-your-own MCP servers route through the Agent 365 Tooling Gateway.

ValueKnow what every agent can pick up.

NotePreview.

Where you see it Microsoft 365 admin center

Read moreManage the tools gatewayAgent 365 tooling

G-7

COMPLIANCE: RETENTION, EDISCOVERY, COMMUNICATION COMPLIANCE

Wool Store

The fleece is graded, stored and kept for as long as it’s needed. Purview applies retention, eDiscovery and communication compliance to agents.

HowAgent instances are switched on for audit, data classification and Compliance Manager AI assessments automatically. For anything else, add the agent instance to a policy as you would a user.

ValueAudit-ready, fleece by fleece.

NotePurview features need E7 or Agent 365.

Where you see it Microsoft Purview

Read morePurview for Agent 365

Fence-o-pedia

Which bit of the farm is which bit of Agent 365?

  • Five-bar gate→Lifecycle actions: activate, block, delete, approve (G-1)
  • Sorting race→Rule-based lifecycle automation (G-2)
  • Dry-stone walls→Policy templates bundling Entra, Purview, SharePoint and Defender (G-3)
  • Noticeboard→Owners, sponsors and Entra access packages (G-4)
  • Cattle grid→Conditional Access for agents (G-5)
  • Tool shed→Tools gateway: allow or block MCP servers (G-6)
  • Wool store→Purview retention, eDiscovery and communication compliance (G-7)
  • Ear tag→Microsoft Entra Agent ID (O-2)
  • Shepherd→Agent 365: the control plane that walks the paths
Secure

Shepherds and sheepdogs

Agent 365 extends Microsoft’s identity, data and threat protection to every agent. Meet the party: each one is a Microsoft security product doing its job for agents.

MICROSOFT PURVIEW

The Head Shepherd

Special move

Protect data and stop the fleece leaving the farm

DLP can block or audit agent-to-human and human-to-agent traffic in Teams, OneDrive, SharePoint and email. Encrypted labels must grant the agent VIEW and EXTRACT rights. Use DSPM › AI observability.

Read morePurview for Agent 365

Equipped: Microsoft Purview

MICROSOFT DEFENDER

The Sheepdog

Special move

Detect threats and block unsafe tool calls in real time

Real-time protection checks tool calls through Work IQ MCP before they run. The default rule only audits; custom rules block. Posture management finds misconfigurations and attack paths to critical assets.

Read moreDetection and huntingReal-time protectionGet started

Equipped: Microsoft Defender

MICROSOFT INTUNE

The Yard Dog

Special move

Only let agents run from compliant devices

Blocking a shadow AI agent creates an Intune policy (“A365 - Block OpenClaw”), which can take 15 minutes to 8 hours to apply.

Read moreIntune with Agent 365Shadow AI

Equipped: Microsoft Intune

MICROSOFT ENTRA

The Hill Shepherd

Special move

Spot risky agent sign-ins and odd behaviour

Risk-based Conditional Access, ID Protection and network controls for Copilot Studio agents.

Read moreEntra capabilities for Agent 365

Equipped: Microsoft Entra

Included

With Microsoft 365 Enterprise, Business, Education and Frontline plans

  • Registry inventory
  • Basic governance actions
  • Rule-based lifecycle automation
  • External registry sync

Agent 365 or E7

Needs Microsoft 365 E7 / G7 or an Agent 365 licence

  • Observability and the Agent map
  • Policy templates and tenant-wide tool control
  • Entra access packages, lifecycle policies and Conditional Access
  • Every Purview, Defender and Intune capability for agents
  • The registry Graph API

Good to know

Availability

  • Generally available for Commercial since 1 May 2026, licensed per user
  • Standalone, or included in Microsoft 365 E7
  • Works best with Microsoft E5 as a prerequisite
  • Purview items and some Defender and Intune items aren’t available in GCC
