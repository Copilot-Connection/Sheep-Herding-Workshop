# Lab 3 - Build an Agent Builder agent
Time: 10 minutes
Objective: Create a grounded New Joiner agent in Microsoft 365 Copilot, test its boundaries, and share it with a controlled audience. Or go wild and create your own idea using your sample site!
Detailed walkthrough
Part A - Create and configure
1.	Open the Microsoft 365 Copilot app on the web and confirm that Work IQ is selected.
2.	In the left pane, select New agent. On Describe, add your scenario for a new joiner.
3.	Review each update Agent Builder proposes.
4.	Select Configure. Set Name to New Joiner Agent [Your Name] (or add your own sheep pun). Build your own description.
5.	In Instructions, review the details and confirm you are happy with instructions.
6.	In Knowledge, select Add or the plus button, choose SharePoint or Work content, search for the workshop site Ewe Belong Here - Home, and select some files.
7.	If a general-knowledge control is shown, disable it for this grounded exercise. Do not add email, Teams, or broad organisational knowledge.
8.	In Suggested prompts, add some sample prompts
9.	Select Save or Create. Wait for the success message before leaving the page.
Part B - Run a repeatable test
1.	Select Try it and start a new conversation. 
2.	If a grounded answer fails, verify that the file is supported, indexed, readable by the signed-in user, not encrypted, and selected as a knowledge source. Tighten the source description or instructions and retry.
Part C - Share and verify
1.	Select Share. Enter the exact workshop security group “Sheep Herders”, grant user access only, and review the audience before confirming.
2.	Do not select organisation-wide access. If publishing approval is offered, add the workshop purpose, owner, test audience, and expiry date to the submission.
3.	Return to Microsoft 365 admin centre > Agents > All agents > Registry. Search for the exact agent name and open it.
