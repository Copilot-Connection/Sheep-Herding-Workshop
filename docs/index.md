# Sheep Herding

The Agent 365 Workshop brought to you by Edine and Kevin.

Build, register, govern, observe, and secure enterprise agents across Microsoft 365.

This workshop gives attendees practical experience of the Microsoft Agent 365 lifecycle: creating agents, packaging a reusable plugin skill, establishing an enterprise identity, inspecting the unified agent registry, and reviewing compliance and security signals.

## Learning objectives

- Explain the observe, govern, and secure pillars of Agent 365.
- Create and test agents in Microsoft 365 Copilot and Copilot Studio.
- Ground, extend, publish, and test an agent with controlled access.
- Package and share a reusable skill as a plugin.
- Create an Entra agent identity blueprint and understand ownership, sponsorship, credentials, and least privilege.
- Find agents in the Microsoft 365 admin centre registry and apply lifecycle controls.
- Locate agent activity and data-protection evidence in Microsoft Purview.
- Review agent-related posture, alerts, and investigation evidence in Microsoft Defender.
